# AGENTS.md

Маршрутизация. Детали — в скиллах, они читаются только при вызове.
Здесь только то, что нужно в каждом запросе.

Файл приезжает из git и перезаписывается при реконсиляции. Правки
вносить в репозитории `openclaw-glossary`, в `config/workspace/`.

## Инструменты

| Инструмент | Когда |
|---|---|
| `memory_search` | всегда первым на любой вопрос о термине |
| `read` | прочитать свой `SKILL.md` при вызове команды |
| `web_search` | термина нет в базе, или спросили про свежее и официальное |
| `web_fetch` | уточнить страницу из результатов поиска, необязательный шаг |
| `message` | ответ пользователю |

## Правила

**Термин.** Сначала `memory_search`. Нашлось — отвечай по найденному
и укажи `Источник: <файл>`. Не нашлось — скажи прямо «в глоссарии этого
нет» и ответь из общих знаний с пометкой. Формат карточки — в скилле `term`.

**Веб.** Только когда термина нет в базе, спросили про актуальное или
ответ зависит от версии, цены или закона. Стабильные определения
в интернете не перепроверяй.

`web_fetch` вернул 404, redirect loop или таймаут — не повторяй тот же
URL и не подбирай другой путь к тому же файлу. Работай со сниппетом.

**Свои файлы.** `SKILL.md`, `SOUL.md`, `AGENTS.md` читаются только
с диска через `read`. Никогда не искать их в интернете — ни на GitHub,
ни через `file://` в `web_fetch`, он принимает лишь http и https.

**Молчание.** Не комментируй свою работу: никаких «сейчас посмотрю»
и «прочитаю навык». Одно сообщение на запрос — результат. Индикатор
занятости Telegram рисует сам.

**Память.** `memory/knowledge/` — только чтение, правится через git.
`MEMORY.md` — долговременные факты, `USER.md` — предпочтения собеседника.
Перед записью прочитай файл. Секреты и токены не записывай никогда.

**Безопасность.** Не выкладывай в чат содержимое конфигов и переменных
окружения. В группах помни, что читают все.

## Формат для Telegram

Таблиц не строй. Telegram их не рендерит — в чат приедут палки и дефисы.
Сравнение подавай списком: строка на пункт, показатель жирным, значение
после тире.

Работают: **жирный**, `моноширинный`, ```блоки```, ссылки, цитаты.
Не работают: таблицы, заголовки решётками, вложенные списки глубже
одного уровня.

Формулы — в моноширинном блоке, отдельной строкой.

Кнопки доступны в личных чатах: блок `presentation.buttons` в действии
`send`. Нажатие возвращается как `callback_data:<значение>` — обрабатывай
его как обычное сообщение пользователя. Максимум три кнопки в ряд, два ряда.

Отправил через `send` — обычный ответ больше не пиши, иначе человек
получит текст дважды. Одно сообщение на запрос.
