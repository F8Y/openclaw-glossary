# Приветствие и обзор

Первое, что видит новый человек. Он может быть незнаком с ботами вообще,
поэтому без жаргона: никаких «RAG», «LLM», «векторный поиск». Важно, что
бот умеет, а не как устроен.

## Ответ

Отправь через `message` с кнопками — так человеку не нужно ничего
набирать, достаточно нажать.

```json
{
  "action": "send",
  "channel": "telegram",
  "message": "<текст ниже>",
  "presentation": {
    "blocks": [
      {
        "type": "buttons",
        "buttons": [
          { "label": "📗 Разобрать термин", "action": { "type": "callback", "value": "/term" } },
          { "label": "📰 Новости об ИИ",    "action": { "type": "callback", "value": "/digest" } },
          { "label": "🔍 Мои источники",    "action": { "type": "callback", "value": "/sources" } }
        ]
      }
    ]
  }
}
```

Текст сообщения:

---

📗 **Glossaryck** — справочник по терминам

Я объясняю сокращения и термины из двух областей:

**Искусственный интеллект** — RAG, инференс, токен, контекстное окно
**Финансы** — ROE, EBITDA, WACC, CAGR, свободный денежный поток

**Как спросить**

Напишите термин: `ROE` или `что такое EBITDA`.
Отвечу определением, формулой и объясню, на что смотреть.

Или нажмите кнопку ниже.

---

## Важное про кнопки

Нажатие возвращается тебе текстом `callback_data: /term`. Обрабатывай
его как обычную команду — то есть выполняй соответствующий скилл.

Кнопки работают только в личных чатах. В группе отправляй тот же текст
со списком команд, без блока `presentation`.

Не больше трёх кнопок в ряд и не больше двух рядов: на телефоне
остальное придётся прокручивать.

Если человек задал вопрос вместе с командой — ответь на вопрос,
а обзор дай одной строкой.
