# Telegram UI для Glossaryck

## Что изменилось

Статические экраны больше не генерируются моделью. Локальный плагин
`glossary-ui` перехватывает команды до LLM и сразу возвращает обычный текст
с нативной inline-клавиатурой Telegram.

Плагин обрабатывает:

- `/start` без параметров, `/menu` и `/about` — главное меню;
- `/explain` — подсказку и примеры терминов;
- `/knowledge` — выбор раздела и каталог;
- `/sources` — краткую политику источников и официальные ссылки.

`/digest` намеренно остаётся у агента: для него нужны веб-поиск, отбор и
суммаризация. Обычный текст с термином тоже остаётся у агента и RAG.

## Как работают кнопки

- Плагин отдаёт нативную `channelData.telegram.buttons`, а не общий
  `presentation`. Общий Telegram-рендерер OpenClaw добавляет в текст fallback
  со всеми командами, поэтому меню дублировалось над клавиатурой.
- Навигация использует callback namespace `glossary:*` и редактирует текущее
  сообщение на месте: каталог не превращается в длинную ленту экранов.
- Нажатие на термин возвращает `submitText: /start term_<payload>` в обычный
  входящий маршрут OpenClaw. Пользователь не видит техническую команду, а
  карточку по-прежнему строят скилл `term` и локальная память.
- Кнопка дайджеста аналогично отправляет `/digest` агенту; ссылки источников
  остаются обычными URL-кнопками Telegram.
- В одном ряду не больше двух кнопок. На каждом вложенном экране есть путь
  назад и в главное меню.

Команда `/start` зарегистрирована с `acceptsArgs: false`. Поэтому простой
`/start` открывается мгновенно, а `/start term_ROE` не перехватывается плагином
и продолжает идти по существующему маршруту агента.

## GitOps-доставка

Исходник находится в `extensions/glossary-ui/`. На каждом reconcile пакет
синхронизируется в:

```text
${OPENCLAW_STATE_DIR}/config/extensions/glossary-ui
```

Плагин включён декларативно через `config/openclaw.batch.json`. Если изменился
его код или конфиг OpenClaw, reconcile один раз перезапускает gateway. Если
ничего не изменилось, пятиминутный таймер не прерывает диалоги рестартом.

## Проверка после выкладки

Проверить, что runtime увидел команды:

```bash
sudo docker compose \
  --env-file /run/openclaw/env \
  -f /opt/openclaw-glossary/docker-compose.yml \
  run --rm cli plugins inspect glossary-ui --runtime --json
```

Затем проверить в Telegram:

1. `/menu` показывает четыре крупные кнопки без паузы на модель.
2. `База знаний` показывает 28 определений; в каждом разделе видны кнопки
   терминов, а нажатие открывает карточку агента.
3. `Источники` показывает кликабельные официальные сайты.
4. `Новости об ИИ` запускает существующий динамический дайджест.
5. `/start term_ROE` по-прежнему объясняет ROE, а не открывает меню.

## Тихий прогресс

Пока агент работает, Telegram показывает одну дружелюбную заглушку вроде
`🦞 Lobstering…` или `🔎 Ищу и проверяю…`. Названия инструментов, пути к
файлам, reasoning и итоговая строка `N tool calls` скрыты настройками
`streaming.progress.toolProgress: false` и `reasoningDefault: off`.

На входящее сообщение бот временно ставит реакцию `👀` и убирает её после
ответа. Финальный ответ остаётся обычным чистым сообщением.

Старый диалог может хранить собственные overrides поверх defaults. После
выкладки один раз отправьте в нём `/reasoning off` и `/verbose off`.
